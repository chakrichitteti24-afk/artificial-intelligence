## 🛠️ Prerequisites & Setup

1. **Install Python**: Ensure you have Python 3.x installed on your system.
2. **Clone the Repository**:
   ```bash
   git clone <repository_url>
   cd AI-LAB-JNTUA-R23
   ```
3. **Install Dependencies** (Required for visualization graphs):
   ```bash
   pip install -r requirements.txt
   ```

## 📝 Usage
Navigate to the directory of the experiment you want to execute and run the python file. For example:
```bash
cd Experiment-01-Breadth-First-Search
python bfs.py
```

## ✨ Code Quality & Features
- **Clean Code**: Follows PEP8 conventions.
- **Modular Design**: Uses functions and classes appropriately.
- **Well-Commented**: Each step in the code is explained clearly.
